# Heart Disease Prediction

A machine learning project that uses **Logistic Regression** to predict the presence of heart disease based on patient health indicators. Implemented using Python and scikit-learn.

## Project Overview

- **Model:** Logistic Regression
- **Task:** Binary Classification
- **Dataset:** 303 records with 13 input features
- **Train-Test Split:** 80% training, 20% testing
- **Evaluation Metric:** Accuracy

## Results

| Metric | Accuracy |
|---|---|
| Training Accuracy | 85.12% |
| Testing Accuracy | **81.97%** |

## Technologies Used

Python · NumPy · Pandas · Scikit-learn · Jupyter Notebook

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/fahadCoder/Heart-Disease-Prediction.ipynb.git
```

**2. Install dependencies**

```bash
pip install numpy pandas scikit-learn
```

**3. Run the notebook**

- Open `Project_10_Heart_Disease_Prediction.ipynb` in Google Colab or Jupyter Notebook.
- Provide the dataset as `data.csv` at the path specified in the notebook (`/content/data.csv` in Colab).
- Execute the cells sequentially to train and evaluate the model.
